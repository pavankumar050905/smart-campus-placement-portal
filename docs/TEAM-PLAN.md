# Four-Member Work Split

Use these placeholders until the team names are known.

## Member 1 — Frontend and UX
- React layout, navigation, responsive design, login/register pages.
- Student dashboard, profile editor, job search and application tracking.
- Assessment generation, timed test-taking, result review and history UI.

## Member 2 — Backend and Security
- Express API structure, JWT auth, role middleware, input validation.
- User/student/recruiter models and profile endpoints.
- Assessment access rules, server-side expiry and grading, API tests.

## Member 3 — Recruitment Workflow and Analytics
- Jobs, eligibility engine, applications and status transitions.
- Recruiter dashboard, admin approvals and placement metrics.
- Recruiter-assigned assessments and assessment analytics.
- Synthetic demo dataset and workflow test cases.

## Member 4 — AI and Integration / QA
- Groq career advice, job matching and skill-gap guidance.
- Personalised MCQ generation and local fallback question bank.
- Integration tests, report/demo documentation and local setup validation.

## Shared workflow
- Use feature branches and pull requests.
- Never commit `.env` or real student data.
- Keep README setup steps updated.
- Every feature must include a test or documented manual test.
- Review authentication and authorisation changes before merging.
